ZeeU AI - Knowledge Base

Syfte
- Dessa filer är "källan till sanning" för hur portalen fungerar och hur vår data ser ut.
- De används för att ge AI:n kontext så den kan ge bättre svar (både "hur gör jag i portalen?" och "vad säger datan?").

Struktur
- Knowledge/portal: produkt-/funktionsdokumentation för portalen
- Knowledge/db: data dictionary per datakälla (t.ex. Jeeves)

Riktlinjer
- Skriv kort, tydligt och utan kundspecifik data (ingen PII).
- Använd konsekventa rubriker och begrepp (se glossary).
- Om en regel ändras i portalen/databasen: uppdatera dokumentet här samtidigt.
