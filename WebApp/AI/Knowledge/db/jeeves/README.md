# Data Dictionary - Jeeves (SQL Server)

Detta är en data dictionary för de tabeller/kolumner som AI-funktioner typiskt använder.

Mål
- Hjälpa AI att välja rätt tabeller/kolumner
- Förklara join-regler (även när FK saknas i databasen)
- Definiera KPI:er och affärsbegrepp

Filer
- `jeeves-orders.md`: order/kund-tabeller och domänhints för SQL-frågor
- `jeeves-invoices.md`: faktura-tabeller och domänhints för SQL-frågor
- `joins.md`: viktiga joins och relationer
- `metrics.md`: definitioner för KPI:er/insikter
- `synonyms.yml`: synonymer för bättre tolkning av användarfrågor
