# Web Approval

## Syfte
Web Approval används för att hantera attester (godkännanden) av flöden, t.ex. inköpsorder.

## Vanliga flöden
- Se vad som väntar på attest
- Öppna ett ärende (t.ex. inköpsorder) för granskning
- Godkänn eller neka enligt gällande process

## Tips
- Om en attest “låser” ett flöde: prioritera att godkänna/avslå för att undvika stopp i inköp/leverans.

## Koppling till Action Center
Action Center kan visa insikter som “Attester väntar på godkännande” och länka direkt till Web Approval.
