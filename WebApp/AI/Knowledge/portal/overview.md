# Portal Overview (ZeeU Hub)

## What this portal is
- ZeeU Hub är en webbportal som visar affärsinsikter och arbetsflöden för användare kopplade till en tenant (företag).
- Portalen innehåller dashboard, order, fakturor och web approval (attester) beroende på roll och behörighet.

## Roles & access
- Administrator: kan konfigurera och se mer administrations-/AI-funktioner.
- User / SuperUser: ser moduler baserat på tenant + bolag + submodule-permissions.

## Key concepts
- Tenant: vilken kundmiljö/organisation användaren tillhör.
- Company (bolag): bolagskod som filtrerar data (t.ex. `ForetagKod` i Jeeves).
- Action Center: samlingsplats för avvikelser/notiser som kräver åtgärd eller extra koll.

## Navigation (high level)
- Main Dashboard: översikt, KPI:er, grafer och action center.
- Orders: orderöversikt och orderdetaljer.
- Invoices (Fakturor): obetalda/betalda fakturor, förfallna fakturor och åtgärder.
- Web Approval: attester, t.ex. inköpsorder.
- AI Intelligence: chatt som kan svara med SQL-baserad data (om tillåtet).

## Övriga moduler (beroende på behörighet)
- Excelimport: ladda upp Excel/CSV till staging.
- Inköp: skapa och hantera inköpsorder.
- Kundsupport: hjälp och kontaktvägar.
